# book_manager 開発ロードマップ

## 1. 目的

本ロードマップは、book_manager Version 1.0 の完成条件と、Version 1.0以降に検討する機能を整理するためのものである。

Version 1.0では、書籍情報の登録・編集・検索・外部書誌情報取得を中心とした基本機能を、日常的に安心して利用できる品質まで仕上げることを目標とする。

---

## 2. Version 1.0 完成方針

Version 1.0では、次の状態を目指す。

* 書籍情報を安全に登録・更新・削除できる。
* ISBNから外部書誌情報を取得できる。
* 表紙画像を取得・保存・再表示できる。
* 登録済み書籍を複数条件で検索できる。
* 一覧を任意の項目で並べ替えできる。
* 検索結果を維持したまま並べ替えできる。
* 入力ミスや外部サービス障害時に適切なエラー表示が行われる。
* 既存データを維持したままDBスキーマを更新できる。
* 自動テストによって主要機能の回帰を検出できる。
* 開発用コードや設定情報が整理され、通常利用できる状態になっている。

## 7. Version 1.0以降

Version 1.0リリース後は、実際にbook_managerを利用しながら改善点を収集する。

新機能の追加を優先するのではなく、実利用で感じた不便や不足を基準としてVersion 1.1以降の開発内容を決定する。

Version 1.0は「すべての機能を搭載した完成版」ではなく、「日常的に安心して使い始められる最初の正式版」と位置付ける。
