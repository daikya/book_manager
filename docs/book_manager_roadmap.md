# book_manager 開発ロードマップ

## 1. 目的

本ロードマップは、book_managerの各Versionにおける完成条件と、今後検討・実装する機能を整理するためのものである。

Version 1.0では、書籍情報の登録・編集・検索・外部書誌情報取得を中心とした基本機能を、日常的に安心して利用できる品質まで仕上げた。

Version 1.1では、Version 1.0を実際に利用しながら、データ保護と日常的な操作性の向上を目的とした改善を行う。

---

## 2. Version 1.0 完成方針

Version 1.0では、次の状態を完成条件とした。

* [x] 書籍情報を安全に登録・更新・削除できる。
* [x] ISBNから外部書誌情報を取得できる。
* [x] 表紙画像を取得・保存・再表示できる。
* [x] 登録済み書籍を複数の検索項目から検索できる。
* [x] 一覧を任意の項目で並べ替えできる。
* [x] 検索結果を維持したまま並べ替えできる。
* [x] 入力ミスや外部サービス障害時に適切なエラー表示が行われる。
* [x] 既存データを維持したままDBスキーマを更新できる。
* [x] 自動テストによって主要機能の回帰を検出できる。
* [x] 開発用コードや設定情報が整理され、通常利用できる状態になっている。

Version 1.0.0は、RC1による最終レビュー、GUI主要操作の手動確認、308件の自動テスト全件成功を経て正式リリースした。

## 4. Version 1.0 リリース

Version 1.0.0を最初の正式版としてリリースした。

Version 1.0は「すべての機能を搭載した完成版」ではなく、「日常的に安心して使い始められる最初の正式版」と位置付ける。

Version 1.0以降は、実際にbook_managerを利用しながら改善点を収集し、新機能の追加そのものを目的とせず、実利用で感じた不便や不足を基準として開発内容を決定する。

## 5. Version 1.1

### 5.1 テーマ

**データ保護と日常利用の改善**

Version 1.0で完成した基本機能を維持しながら、登録した蔵書データをより安全に保護し、日常的な操作をより便利にする。

Version 1.1では新機能を過剰に追加せず、以下の3機能を主要スコープとする。

---

### 5.2 自動バックアップ

SQLiteデータベース`data/books.db`を安全に自動バックアップする機能を追加する。

#### 基本方針

* [ ] SQLite Backup APIを利用する。
* [ ] バックアップ対象は`data/books.db`とする。
* [ ] 表紙画像キャッシュ`cache/covers`はバックアップ対象外とする。
* [ ] `backups`ディレクトリへバックアップDBを保存する。
* [ ] バックアップファイル名に日時を含める。
* [ ] 一定時間以上バックアップが作成されていない場合に自動実行する。
* [ ] 保存するバックアップの世代数を制限する。
* [ ] 上限を超えた古いバックアップを自動整理する。
* [ ] バックアップ失敗時もアプリケーションの起動は継続する。
* [ ] バックアップ失敗時は利用者へ通知する。
* [ ] バックアップ処理の自動テストを追加する。

#### 設計時に決定する項目

* バックアップ実行タイミング
* バックアップ間隔
* 保存世代数
* ファイル名規則
* バックアップ失敗時の通知方法
* SQLite接続とBackup APIの責務分離
* 将来の復元機能との関係

---

### 5.3 CSVエクスポート

登録済みの書籍情報をCSV形式で外部へ出力できる機能を追加する。

#### 基本方針

* [ ] Python標準ライブラリ`csv`を利用する。
* [ ] book_managerに保存されているデータを可能な限り加工せず出力する。
* [ ] 「内容紹介」「備考」などに含まれる改行を保持する。
* [ ] カンマやダブルクォートは`csv`モジュールにより適切にエスケープする。
* [ ] `None`は空欄として出力する。
* [ ] 文字コードはUTF-8 BOM付き（`utf-8-sig`）を第一候補とする。
* [ ] Windows版Excelで扱いやすいCSV形式とする。
* [ ] CSV出力先を利用者が選択できるようにする。
* [ ] CSVエクスポート処理の自動テストを追加する。

#### 設計時に決定する項目

* CSVへ出力するカラム
* カラム順
* ヘッダー名
* 日時情報を出力するか
* 表紙画像URL・キャッシュパスを出力するか
* デフォルトファイル名
* エクスポート対象を全件とするか、検索結果も対象にするか
* 将来のCSVインポートとの互換性

---

### 5.4 一覧ヘッダークリックによるソート

書籍一覧の列見出しをクリックすることで、その項目による並べ替えを実行できるようにする。

#### 基本方針

* [ ] Version 1.0で実装済みのソート処理を再利用する。
* [ ] 列見出しクリックで対象項目を切り替える。
* [ ] 同じ列を再度クリックした場合は昇順・降順を切り替える。
* [ ] 検索結果を表示している場合も検索条件を維持する。
* [ ] 現在のソート項目・方向とGUI上の状態を一致させる。
* [ ] 既存の並べ替えコンボボックス・ラジオボタンとの整合性を維持する。
* [ ] ヘッダーソートの動作確認を行う。
* [ ] 必要に応じて関連テストを追加する。

## 8. Version 1.1 開発方針

Version 1.1でもVersion 1.0で確立した開発手順を継続する。

```text
要件整理
↓
設計
↓
設計レビュー
↓
実装
↓
自動テスト
↓
GUI・実機確認
↓
ドキュメント更新
↓
リリースレビュー
```

一つの機能を完成させてから次の機能へ進み、複数の大きな変更を同時に進行させない。

Version 1.1では、次の順番を基本とする。

1. 自動バックアップ
2. CSVエクスポート
3. 一覧ヘッダークリックによるソート
