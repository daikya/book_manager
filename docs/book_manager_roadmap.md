# book_manager 開発ロードマップ

## 1. 目的

本ロードマップは、book_managerの各Versionにおける完成条件と、今後検討・実装する機能を整理するためのものである。

Version 1.0では、書籍情報の登録・編集・検索・外部書誌情報取得を中心とした基本機能を、日常的に安心して利用できる品質まで仕上げた。

Version 1.1ではデータ保護と日常利用を改善し、Version 1.2では検索と一覧操作を改善した。

Version 1.3では、登録済み書籍の状態をより分かりやすく管理できるよう、蔵書の状態管理と日常利用の改善を進める。

---

## 2. Version 1.0 完成方針

Version 1.0では、次の状態を完成条件とした。

* [x] 書籍情報を安全に登録・更新・削除できる。
* [x] ISBNから外部書誌情報を取得できる。
* [x] 表紙画像を取得・保存・再表示できる。
* [x] 登録済み書籍を複数の検索項目から検索できる。
* [x] 一覧を任意の項目で並べ替えできる。
* [x] 検索結果を維持したまま並べ替えできる。
* [x] 入力ミスや外部サービス障害時に適切なエラー表示が行われる。
* [x] 既存データを維持したままDBスキーマを更新できる。
* [x] 自動テストによって主要機能の回帰を検出できる。

Version 1.0.0は、RC1による最終レビュー、GUI主要操作の手動確認、308件の自動テスト全件成功を経て正式リリースした。

Version 1.4では、登録済みデータを安全に取り込み、必要に応じて復元できる機能を追加した。

新しい管理項目を増やすのではなく、既存データの移行性と復旧性を高めることを目的とした。

主要スコープは次の2機能とする。

1. CSVインポート
2. バックアップからの復元

---

### 9.2 CSVインポート

既存のCSVエクスポート機能と対応するCSVインポート機能を追加した。

#### 基本方針

* [x] CSVファイルから書籍データを取り込めるようにした。
* [x] Version 1.3時点のCSVエクスポート形式との互換性を基本とした。
* [x] 読書状態・お気に入り・評価を含めて取り込めるようにした。
* [x] Book Manager自身が出力したCSV形式をインポート対象とした。
* [x] ISBNまたは雑誌コードが既存データと重複する場合は、その行をスキップするようにした。
* [x] CSVインポートによって既存データを自動更新しない構成とした。
* [x] 不正な行が存在しても正常な行の登録を継続し、不正な行だけを除外するようにした。
* [x] インポート結果として登録件数・スキップ件数・エラー件数を確認できるようにした。
* [x] 既存機能に回帰がないことを確認した。
* [x] 必要な自動テストおよび実機確認を行った。

---

### 9.3 バックアップからの復元

既存のバックアップ機能で作成したバックアップから、データベースを安全に復元できる機能を追加した。

#### 基本方針

* [x] GUIから復元対象のバックアップを選択できるようにした。
* [x] 復元前に確認ダイアログを表示するようにした。
* [x] 復元前に現在のデータベースを強制バックアップするようにした。
* [x] SQLiteデータベースとして正常で、Book Manager用DBとして利用可能なバックアップのみ復元対象とした。
* [x] 現在のアプリケーションより新しいスキーマVersionのバックアップを拒否するようにした。
* [x] 復元前バックアップに失敗した場合は復元処理を開始しない構成とした。
* [x] 復元完了後に書籍一覧を再読み込みし、GUIへ結果を通知するようにした。
* [x] 既存のバックアップ機能との整合性を維持した。
* [x] 既存機能に回帰がないことを確認した。
* [x] 必要な自動テストおよび実機確認を行った。

## 10. Version 1.5

### 10.1 テーマ

**蔵書の絞り込みと検索機能の強化**

Version 1.5では、Version 1.2で実装した複合条件検索と、Version 1.3で追加した読書状態・お気に入り・評価を組み合わせ、登録済みの蔵書から目的の書籍をより簡単に探せるようにする。

既存の検索・並べ替え機能との整合性を維持しながら、個人利用で分かりやすく使えるシンプルな検索操作を優先する。

主要スコープは次の2項目とする。

1. 読書情報による検索・絞り込み
2. 検索GUIおよび起動時表示の改善

---

### 10.2 読書情報による検索・絞り込み

既存の書籍名・著者名・出版社・ISBN・雑誌コードによる複合条件検索へ、読書状態・お気に入り・評価による絞り込み条件を追加する。

#### 基本方針

* [ ] 読書状態による絞り込みに対応する。
* [ ] 読書状態は「すべて」「未設定」「未読」「読書中」「読了」から選択できるようにする。
* [ ] お気に入りによる絞り込みに対応する。
* [ ] お気に入りは「すべて」「お気に入りのみ」「お気に入り以外」から選択できるようにする。
* [ ] 評価による絞り込みに対応する。
* [ ] 評価は「すべて」「未評価」「★1以上」「★2以上」「★3以上」「★4以上」「★5」から選択できるようにする。
* [ ] 既存5条件と新しい3条件をすべてAND条件として組み合わせる。
* [ ] 既存の書籍名・著者名・出版社の部分一致検索を維持する。
* [ ] 既存のISBN・雑誌コードの検索仕様を維持する。
* [ ] すべての検索条件が未指定の場合は全件表示する。
* [ ] 検索結果を維持したまま既存の並べ替え機能を利用できるようにする。
* [ ] ヘッダークリックによる並べ替えでも検索条件を維持する。
* [ ] 「検索条件クリア」で新しい絞り込み条件を含む全検索条件を初期状態へ戻す。
* [ ] 既存機能に回帰がないことを確認する。
* [ ] 必要な自動テストおよび実機確認を行う。

---

### 10.3 検索GUIの改善

* [ ] 検索エリアを3行構成のまま維持する。
* [ ] 1行目へ書籍名・著者名・出版社・ISBN・雑誌コードを配置する。
* [ ] 2行目へ読書状態・お気に入り・評価・検索・検索条件クリアを配置する。
* [ ] 3行目へ既存の並べ替え操作を配置する。
* [ ] 書籍名・著者名・出版社とISBN・雑誌コードの用途を考慮して入力欄の横幅を調整する。
* [ ] 新しい検索条件を追加するためにメインウィンドウの縦サイズを増加させない。
* [ ] 最小ウィンドウサイズでも検索操作が実用可能な配置とする。
* [ ] 既存の書籍情報表示領域および書籍一覧を不必要に圧迫しない。
* [ ] GUI実機確認を行い、操作性と視認性を優先して最終調整する。
