# Version 2.7 Excel移行・書誌情報補完設計

設計日：2026年10月2日。実装前の設計であり、現行Version 2.6.0の動作を変更したものではない。

## 1. 目的と操作の分離

既存のExcel読書記録を保持して登録し、その後、利用者が選択した1冊だけを検索・補完する。

Excel読み込み・検査・登録は外部APIを呼び出さない。起動時、取込直後、一覧表示時にも自動候補検索しない。

## 2. 確認した現行仕様

- BookItemには通常のisbnとcompletion_monthがある。参照ISBNと開始月の専用項目はない。
- ReadingHistoryのstarted_on・completed_onは任意文字列としてModelに保持する。
- 日付Validatorと完全データZIPの事前検査はYYYY-MM-DDのみ受け付ける。
- DBスキーマVersionは7。履歴にはstarted_on <= completed_onの文字列比較制約がある。
- 月別集計はcompleted_onの年・月部分を使用する。
- 完全データZIPは形式Version 1、固定の5ファイル、固定ヘッダー。参照ISBNは含まれない。
- 書籍の現在状態と読書履歴は独立している。この基本仕様を維持する。

## 3. 年月精度の読書履歴

started_onとcompleted_onを、YYYY-MMまたはYYYY-MM-DDを保持するTEXTとして拡張する。文字列長から精度を判別できるため、精度カラムは追加しない。

| 値 | 意味 |
| --- | --- |
| 2006-05 | 2006年5月。日は不明 |
| 2006-05-20 | 2006年5月20日 |
| NULL | 未設定 |

年のみの値は今回受け付けない。既存の完全な日付は変更しない。保存時の正規形はASCII数字とハイフンとする。

GUIの項目名は「開始日・年月」「読了日・年月」とし、両書式の入力例を示す。月のみの値を完全な日付に見せない。

### 前後関係の判定

年月は比較時だけ、その月の初日から末日までの範囲として解釈する。日付は同じ日を下限・上限とする。比較用の日付を保存値へ書き戻さない。

開始の下限が終了の上限より後なら、矛盾が確定するため拒否する。それ以外は登録を許可する。範囲が重なり順序を確定できない場合は、検査画面で精度の説明を示す。

| 開始 | 終了 | 判定 |
| --- | --- | --- |
| 2026-05-20 | 2026-05 | 許可。終了日は不明 |
| 2026-05 | 2026-05-10 | 許可。開始日は不明 |
| 2026-06 | 2026-05-31 | 拒否 |
| 2026-05-20 | 2026-05-10 | 拒否 |
| 2026-05 | 2026-05 | 許可 |

両方の値を同じValidatorで検証する。DB制約も同じ判断に合わせて変更し、従来の単純文字列比較を残さない。

### 並び順と集計

履歴は読了値、開始値、登録日という既存の優先順を維持する。異なる月は年月順、同月では完全日付を日順、月精度の記録をその後、同値はID降順とする。同月の月精度の記録について、実際の前後関係は断定しない。

completed_onが月精度でも読了記録として数え、その年月の集計に含める。開始のみ・メモのみの履歴は読了数に含めない。

completion_monthは従来のYYYY-MMを維持する。通常の履歴編集で現在状態やcompletion_monthを自動変更しない。Excel取込時は、確認した列割当から書籍の読了年月と履歴を同時に作成できる。

## 4. 参照ISBN

BookItemとbook_itemsへreference_isbn（任意TEXT）を追加する。ISBNの検証・ISBN-13への正規化は通常ISBNと同じ規則を使用する。

通常isbnは登録対象の版のISBN、reference_isbnは別媒体・別版から情報を補完するために利用者が選んだISBNとする。

- Audible・Kindleなどの元の出版形態を保持する。
- 通常ISBNの重複判定にはreference_isbnを含めない。
- 複数の登録記録で同じreference_isbnを共有できる。
- 補完開始時に使用するISBNと用途を表示する。通常ISBNがある場合も参照ISBNへ黙って切り替えない。
- 参照ISBNの検索候補と反映画面に、取得元の書籍名・出版社などを表示する。
- 参照ISBNからの初期補完対象は内容紹介と表紙画像URLとする。
- 元の書籍名・著者・出版社・出版形態は参照先の値へ変更しない。
- 書影は参照版の画像であり、元媒体の画像とは限らないことを表示する。
- 読書情報、評価、お気に入り、タグ、備考を外部取得で更新しない。

内容紹介の既存値は初期選択では維持する。書影変更時は古いcover_image_pathとの整合性を保ち、新URLに古い画像を結び付けない。実際のキャッシュ更新方法は現行CoverImageServiceを確認して定める。

ASIN専用項目、ASIN検索、ISBNなし候補の直接補完は今回の対象外。

## 5. DB移行

スキーマVersionを7から8へ更新する。

1. 更新前DBの検証済みバックアップを作成する。失敗したら移行しない。
2. 1トランザクションでreference_isbnを追加し、履歴テーブルの制約を更新する。
3. 履歴テーブルを再構築する場合はID、書籍ID、日時、メモ、既存日付をそのままコピーする。
4. インデックス、外部キー、削除時CASCADE、自動採番状態を維持する。
5. 件数・データ・外部キーを検証してからuser_versionを8へ更新する。
6. 失敗時はロールバックする。

既存のreference_isbnはNULLとなる。通常ISBNを参照ISBNへ自動移動しない。起動時のDB初期化より前のバックアップ経路を現行main.py・BackupServiceと照合して実装する。

旧スキーマから新Versionへ移行する経路と、新規DBの作成を両方検証する。移行済みDBをVersion 2.6へ戻して利用することは想定しない。

## 6. 完全データZIPの互換性

最新出力をformat_version=2とする。5ファイル構成を維持する。

- book_items.csvでは「ISBN」の直後へ「参照ISBN」を追加する。
- reading_histories.csvの列は維持し、開始・読了の値にYYYY-MMも許可する。
- manifestのdatabase_schema_versionは出力元の実際のVersionを記録する。
- Version 2.7の読込は形式Version 1と2を明示的に対応する。
- Version 1では旧ヘッダーと完全日付だけを受け付け、参照ISBNをNULLへ補う。
- Version 2では新ヘッダーと精度を保った履歴値を検証する。
- manifestを先に検査し、その形式Versionに対応するヘッダー・Parserを選択する。
- 未知の形式Versionは拒否する。形式VersionとDBスキーマVersionを混同しない。
- 空DBへの復元、全件検査、直前バックアップ、単一トランザクションを維持する。

Version 2.6ではVersion 2のZIPを読み込めない。新しいデータを旧形式へ黙って切り捨てて出力しない。GUIと利用説明へ対応Versionを明記する。

単一CSVにも参照ISBNを保持する新ヘッダーを定義し、既存の現行・旧ヘッダーを引き続き読み込む。従来どおり複数読書履歴は単一CSVへ含めず、完全移行にはZIPを使う。具体的な列順は現行CSV Serviceの確認後に確定する。

## 7. Excel取込の基本仕様

.xlsxの1シートだけを選び、見出し行と列を対応付ける。元ファイルは変更しない。

和暦年月・西暦年月・完全日付・Excelの日付値を正規化する。全角数字を扱い、年月精度を保持する。数値を根拠なく日付シリアルとして解釈しない。数式は実行せず、必要なセルの保存済み計算値がない場合は再保存を案内する。

書籍名を必須とし、ISBNなしを許可する。読了月ありは確認画面で「読了」、開始月だけの行は「読書中」を提案し、登録前に確認できるようにする。既存DBの現在状態を自動変更しない。

開始または読了の記録がある行は1回分の履歴として取り込む。履歴情報がない行へ架空の履歴を作らない。タグ列は任意とする。

同名・同著者だけで行を自動統合・除外しない。初期取込は各行を別の書籍記録として保持する。再読として既存書籍に関連付ける場合は、取込前のプレビューで利用者が対象を明示し、版・媒体と書籍項目の相違を確認する。未解決の相違は自動上書きしない。

空行や管理用行は検査画面で除外対象として明示する。「【最終行】」だけの行を除外できる設定を用意し、一般利用者の特定タイトルを無条件に削除しない。

列対応、除外、関連付けを確定したプレビューを実行前に再検証し、バックアップ後に全変更を1トランザクションで登録する。途中例外で書籍・タグ・履歴の部分登録を残さない。

## 8. 候補検索と補完

選択した1冊の書籍名・著者名から利用者の操作でGoogle Booksを検索する。条件を編集でき、巻・版・媒体・取得済みISBNを見て候補を選ぶ。

候補は自動確定しない。紙の版を参照する運用では文庫を優先する目安を示すが、同じ作品・巻かどうかを利用者が確認する。ISBNのない候補は今回のISBN補完に使用できないことを示す。

GUIを止めず、要求の重複・無制限の再試行を防ぐ。画面を閉じた後や対象書籍が変わった後の応答を別の書籍へ反映しない。

確定したISBNから既存取得処理を呼び出し、比較画面で項目を選んで保存する。保存直前に対象の現在値を再確認し、別操作による変更があれば再比較する。

## 9. 必要な検証

- 日付、年月、うるう年、同月混在、明確な逆転、空欄、和暦・全角数字。
- 既存履歴のID・値保持、Version 7から8への更新と途中失敗。
- 月精度を含む読了集計と、開始のみ・メモのみの既存動作。
- 形式Version 1の読込、Version 2の全項目往復一致、未知Version拒否。
- 参照ISBNの共有、通常ISBNの重複判定、単一CSVとの互換性。
- Excel取込がAPIを一度も呼ばないこと、取消・例外でDBを維持すること。
- 再読関連付けと別巻・別媒体の維持、元の内容紹介と改行の保持。
- 候補検索の失敗・利用制限・遅延応答・取消、入力済み情報の保持。
- 検証用保存先での実Excel照合。通常利用DBへ直接試験取込しない。
- Windows配布版、バックアップ・復元、主要既存機能の回帰。

4. Excel読み込み・プレビュー・一括登録・取込GUIを実装する。
5. 候補検索・比較・補完を実装する。
