# 06 GitHub運用

## 最初に覚える操作
`clone`、`status`、`add`、`commit`、`push`、`pull`

## ブランチ
- `main`: 動作確認済み
- `feature/...`: 新機能
- `fix/...`: 不具合修正
- `docs/...`: 設計変更

## コミット例
- `docs: データベース設計書の初版を追加`
- `feat: ISBN検索サービスを追加`
- `fix: 著者名の生没年除去を修正`
- `test: ISBN変換処理のテストを追加`

## タグ
- `v0.1.0`: 基礎設計
- `v0.2.0`: DB基盤
- `v0.3.0`: 基本GUI
- `v0.4.0`: ISBN検索
- `v1.0.0`: 正式版
