# Google Books APIキーの取得方法

book_managerのWindows版（Version 2.6.0）向けの手順です。公式情報確認日：2026年10月2日。

book_managerは、ISBNから書籍情報を取得する際にopenBDとGoogle Books APIを使用します。Google Books APIは、書誌情報・内容紹介・表紙画像URLなどの取得や補完に利用します。ただし、すべての書籍で情報が見つかるとは限りません。

## はじめに

設定は次の順番で行います。

1. Google Cloudでプロジェクトを作成する。
2. Books APIを有効にする。
3. Books APIに利用先を制限したAPIキーを作成する。
4. book_managerの設定画面へ登録する。
5. ISBNからの取得を試す。

### 「プロジェクト」とは？

Google CloudでAPIやAPIキー、利用状況をまとめて管理する単位です。book_managerのソースコードやSQLiteデータベースをアップロードする操作ではありません。

この手順では、設定を管理する入れ物として「book-manager」という名前を使用します。既存プロジェクトを使うこともできます。

### OAuthの設定は必要？

現在のbook_managerは一般公開の書籍情報を取得します。利用者個人のGoogle Booksライブラリなどにはアクセスしません。この用途ではAPIキーを使用し、OAuthクライアントID、OAuth同意画面、サービスアカウントの作成は不要です。

Google Cloud Consoleへのログインと、book_managerがGoogleアカウントの非公開情報へアクセスするための認証は別のものです。前者はAPIキーを管理するために行います。

### 料金・請求先設定について

Google Cloud Consoleには「無料トライアル」「請求先」などの案内が表示されることがあります。プロジェクトの作成、APIの有効化、請求先アカウントの登録は別の操作です。

このマニュアルでは、有料サービスの作成、無料トライアルへの申込み、クレジットカード登録を手順に含めません。book_managerもGoogle Cloud上へサーバーやデータベースを作成しません。

今回確認したBooks APIの公式利用ガイドには、利用料金やカード登録の要否を明確に示す料金表を確認できませんでした。そのため、無条件に無料であることや、請求先登録が必須であることは断定しません。請求先登録を求められた場合は、選択したAPIがBooks APIであることと、その画面に示される条件を確認してから判断してください。

利用上限（クォータ）は、APIを呼び出せる回数などの制限です。料金とは別の条件で、個人利用でも上限や短時間の制限に達する場合があります。「APIとサービス」のBooks APIの画面で利用状況とクォータを確認してください。上限値は固定値としてこの文書には記載しません。

### どのAPIを有効にする？

**Books API**です。サービス名は `books.googleapis.com` です。

この用途のためにGoogle Drive API、Gmail API、Gemini APIなどを有効にする必要はありません。

## 1. Google Cloud Consoleを開く

[Google Cloud Console](https://console.cloud.google.com/)を開き、Googleアカウントでログインします。

初回は利用規約への同意などを求められる場合があります。会社・学校のアカウントでは管理者の制限で操作できない場合があります。

## 2. プロジェクトを作成する

1. 画面上部のプロジェクト選択欄を開きます。
2. 「新しいプロジェクト」を選択します。
3. 名前に「book-manager」などを入力して作成します。
4. 作成したプロジェクトが選択されていることを確認します。

以降、APIの有効化とキー作成は同じプロジェクトで行います。

## 3. Books APIを有効にする

1. 「APIとサービス」→「ライブラリ」を開きます。
2. 「Books API」を検索します。
3. Books APIの詳細を開き、「有効にする」を押します。

すでに有効なら、この操作は不要です。

## 4. APIキーを作成する

1. 「APIとサービス」→「認証情報」を開きます。
2. 「認証情報を作成」→「APIキー」を選択します。
3. 作成画面に「APIの制限」がある場合は、キーを制限する設定を選び、Books APIを指定します。
4. サービスアカウントを通じてAPI呼出しを認証する設定がある場合、この用途では選択しません。
5. 作成し、表示されたAPIキーを登録用に控えます。

現在の公式手順では、作成時にAPI制限を指定します。画面構成が異なり、先にキーが作成される場合は、使用する前に次の節でBooks APIへの制限を設定してください。

APIキーを公開したり、スクリーンショットへ写したりしないでください。

## 5. キーの制限を確認する

「認証情報」で作成したキーを開き、「APIの制限」がBooks APIだけになっていることを確認して保存します。

Books APIが選択肢にない場合は、同じプロジェクトでBooks APIを有効にしたか確認してください。

### アプリケーションの制限との違い

「APIの制限」は、呼び出せるAPIを限定します。「アプリケーションの制限」は、利用元のウェブサイトやIPアドレスなどを限定します。Googleは両方の制限を推奨しています。

book_managerはWindowsから直接通信するデスクトップアプリです。ウェブサイト用のHTTPリファラー、Android用、iOS用の制限はこの利用形態には適しません。

固定の外向きIPアドレスを管理できる環境では、IP制限を検討できます。家庭回線などでIPが変わる場合は、変更後に通信できなくなる可能性があります。この手順ではBooks APIへのAPI制限を設定し、アプリケーションの制限は環境に合わせて判断します。アプリケーション制限を設定しない場合、キーを知る第三者もBooks APIを呼び出せるため、キーの非公開管理と利用状況の確認を行ってください。

## 6. book_managerへ登録する

1. book_managerを起動し、メイン画面の「設定」を押します。
2. Google Books APIキーの入力欄へキーを入力します。
3. APIキー欄の「保存」を押します。
4. 状態が「設定済み」になったことを確認します。

キーはWindowsの利用者環境変数 `GOOGLE_BOOKS_API_KEY` へ保存されます。保存すると起動中のアプリにも反映され、通常は再起動後に登録し直す必要はありません。

「設定済み」はキーが設定されている状態を示します。キーの有効性、Books APIの有効化、通信成功を保証する表示ではありません。

## 7. 登録後の確認・変更・削除

ISBNからの書誌情報取得を試してください。ただし、openBDの情報も利用するため、情報が表示されたことだけではGoogle Books APIの成功を判断できません。必要に応じてConsoleのBooks API利用状況も確認します。

登録済みのキーそのものはbook_managerの画面へ再表示されません。入力欄はマスクされ、状態は「設定済み」「未設定」で表示されます。

変更する場合は新しいキーを入力して「保存」を押します。削除する場合はAPIキー欄の「削除」を押して確認します。

book_managerで削除しても、Google Cloud側のAPIキーは削除されません。キー自体を無効化する場合は、Consoleでも削除してください。

## 8. キーの安全な管理

キーをGitリポジトリ、ソースコード、ログ、公開設定ファイル、画面共有へ含めないでください。

Windowsの利用者環境変数は暗号化された秘密情報保管庫ではありません。同じWindowsアカウントを共有する場合などは、他者から参照され得ることに注意してください。

漏えいした可能性がある場合は、Google Cloud Consoleで該当キーを削除し、新しいキーを作成してbook_managerへ登録します。

## 9. キーを設定しない場合

openBDから取得できる書籍情報は利用できます。Google Books APIの公開情報取得は公式にはAPIキーなどの識別情報を伴う必要があるため、キー未設定でのGoogle Books側の取得成功を前提にしないでください。

キーを登録しても、対象書籍に内容紹介や表紙画像が存在しなければ取得できません。

## 10. 取得できない場合

| 状況 | 確認すること |
| --- | --- |
| 「設定済み」でも取得できない | キーの入力、削除・無効化の有無、同じプロジェクトでのBooks API有効化 |
| キー制限の変更後に失敗する | API制限がBooks APIか、アプリケーション制限が利用元に合うか |
| 利用制限のエラーが出る | Books APIの利用状況・クォータ。連続した再試行を避け、時間を置く |
| 一部のISBNだけ見つからない | ISBNの入力、Google Books・openBDの収録状況 |
| 内容紹介・表紙だけない | 取得元にその項目が存在するか。キー登録だけで情報が増えるとは限らない |
| プロジェクトやキーを作れない | アカウントの権限、会社・学校の管理者による制限 |
| Consoleの画面が異なる | 「APIとサービス」「Books API」「認証情報」「APIキー」を探す |
