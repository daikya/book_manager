# 01 プロジェクト概要

## プロジェクト名
`book_manager`

## 目的
個人が長期間利用できる蔵書管理デスクトップアプリを開発する。

## 対象
文庫、新書、単行本、コミック、雑誌、ムック、写真集、電子書籍、その他。

## 基本方針
- WindowsとmacOSに対応
- SQLiteを使用
- 書誌情報と所有情報を分離
- 表紙画像は外部保存
- 複数取得元のRawデータと採用元を保持
- ユーザー確定項目を自動更新で上書きしない
- 著者・出版社・シリーズ等の表記揺れを正規化
- DBマイグレーション対応
- GitHubで設計書とコードを管理

## 試作版
正式版は新規DBで開始し、試作版`books.db`からの移行は行わない。
