# CSVエクスポート機能 設計書

## 1. 目的

本設計書は、book_manager Version 1.1で追加するCSVエクスポート機能の設計を定義する。

CSVエクスポート機能は、book_managerへ登録した蔵書情報をCSV形式で外部へ保存し、Excelなどの表計算ソフトで確認・加工・保管できるようにすることを目的とする。

Version 1.1では、人が閲覧・利用するためのCSV出力を主目的とし、CSVインポートとの完全な相互互換性は対象外とする。

Version 1.3では、読書ステータス管理機能の追加に伴い、CSVエクスポート対象へ読書状態を追加する。

CSVは人が閲覧・利用するための形式であるため、読書ステータスの内部値ではなく、日本語の表示名へ変換して出力する。

---

## 2. 基本方針

CSVエクスポート機能は、次の方針で実装する。

* Python標準ライブラリ`csv`を利用する。
* 登録済みの書籍情報を全件出力する。
* 利用者が保存先とファイル名を選択できるようにする。
* 文字コードはUTF-8 BOM付き（`utf-8-sig`）とする。
* `None`は空欄として出力する。
* 「内容紹介」「備考」などに含まれる改行は保持する。
* カンマ、ダブルクォート、改行などCSV上で特別な意味を持つ文字は、`csv`モジュールに処理を任せる。
* book_manager内の文字列をCSV出力の都合で置換・削除しない。
* 正常終了時は利用者へ完了を通知する。
* エクスポート失敗時は利用者へエラーを通知する。
* Version 1.1ではCSVインポートは実装しない。
* 読書ステータスは利用者が理解しやすい日本語の表示名へ変換して出力する。
* 読書ステータスが未設定の場合は空欄として出力する。

---

## 3. 出力対象

Version 1.1では、データベースへ登録されている書籍を全件出力する。

選択した書籍だけの出力や、検索結果だけの出力はVersion 1.1の必須機能には含めない。

出力順は、登録順の降順（新しく登録した書籍から）とする。

書籍一覧は`BookService.get_sorted_books()`を利用し、
次の条件で取得する。

```python
books = book_service.get_sorted_books(
    sort_by="registered",
    descending=True,
)
```

---

## 4. CSV出力項目

CSVへ出力する項目は次の12列とする。

| No. | CSVヘッダー | BookItem属性 |
| --- | --- | --- |
| 1 | 書籍名 | `title` |
| 2 | ISBN | `isbn` |
| 3 | 雑誌コード | `magazine_code` |
| 4 | 著者名 | `author` |
| 5 | 出版社 | `publisher` |
| 6 | 出版形態 | `publication_format` |
| 7 | 内容紹介 | `description` |
| 8 | 読了年月 | `completion_month` |
| 9 | 読書状態 | `reading_status` |
| 10 | 備考 | `notes` |
| 11 | 登録日時 | `created_at` |
| 12 | 更新日時 | `updated_at` |

`BookItem`にはこれらの項目が定義されている。

### 4.1 読書状態の出力形式

`reading_status`はbook_manager内部では次の値を使用する。

| 内部値 | CSV出力値 |
| --- | --- |
| `unread` | 未読 |
| `reading` | 読書中 |
| `completed` | 読了 |
| `None` | 空欄 |

CSVエクスポートは人が閲覧・利用することを主目的としているため、`unread`、`reading`、`completed`などの内部値をそのまま出力せず、日本語の表示名へ変換する。

読書ステータスが未設定の場合は、既存の`None`の扱いと同様に空欄として出力する。

読書状態と読了年月は独立した情報として扱う。

そのため、過去に読了した書籍を再読している場合など、`completion_month`に値があり、`reading_status`が`reading`となっている状態もそのままCSVへ出力する。

---

## 5. CSVへ出力しない項目

次の項目はVersion 1.1のCSVには出力しない。

* `id`
* `cover_image_url`
* `cover_image_path`

### 5.1 id

`id`はSQLite内部で書籍を識別するための管理値であり、利用者が蔵書一覧として閲覧するCSVでは必要性が低いため出力しない。

### 5.2 表紙画像URL・キャッシュパス

`cover_image_url`および`cover_image_path`は表紙画像機能の内部管理に使用する情報であり、Version 1.1の「人が読むCSV」という目的には不要と判断する。

将来CSVインポートや完全なデータ交換形式を実装する場合は、別途出力対象へ含めるか検討する。

---

## 6. CSV形式

### 6.1 文字コード

文字コードは次を使用する。

```text
UTF-8 BOM付き
```

Pythonでは次の指定を使用する。

```python
encoding="utf-8-sig"
```

Windows版Excelなどで日本語CSVを扱う際の文字化けを避けやすくすることを目的とする。

### 6.2 改行

`description`および`notes`などに含まれる改行は削除・置換せず、そのままCSVへ出力する。

Python標準の`csv`モジュールにより、必要に応じてフィールド全体をダブルクォートで囲む。

例：

```text
元データ

一度図書館で読んだ。
面白かったため購入した。
続編も購入予定。
```

CSV上では、概念的に次のように保持される。

```csv
"一度図書館で読んだ。
面白かったため購入した。
続編も購入予定。"
```

### 6.3 カンマ

フィールド内にカンマが含まれる場合も、文字列自体は変更しない。

CSV仕様に必要な引用処理は`csv`モジュールへ任せる。

### 6.4 ダブルクォート

フィールド内に`"`が含まれる場合も、文字列自体は変更しない。

CSV仕様に従ったエスケープ処理は`csv`モジュールへ任せる。

### 6.5 None

`BookItem`の値が`None`の場合は、CSV上では空欄として出力する。

### 6.6 読書状態

`reading_status`はCSV出力時に次の日本語表示へ変換する。

```text
unread    → 未読
reading   → 読書中
completed → 読了
None      → 空欄
```

---

## 7. CSVファイル作成方法

CSV出力にはPython標準ライブラリ`csv`を利用する。

概念上は次の形式とする。

```python
with output_path.open(
    "w",
    encoding="utf-8-sig",
    newline="",
) as file:
    writer = csv.writer(file)
```

`newline=""`を指定し、改行処理を`csv`モジュールへ委ねる。

CSVの引用・エスケープ処理を自前では実装しない。

---

## 8. デフォルトファイル名

保存ダイアログで提示するデフォルトファイル名は、次の形式とする。

```text
book_manager_YYYYMMDD_HHMMSS.csv
```

例：

```text
book_manager_20260820_103000.csv
```

日時にはエクスポート実行時点のローカル日時を使用し、
BookManagerApplication側でdatetime.now()から生成する。

---

## 9. CSVエクスポートService

CSV作成処理はGUIから分離し、専用Serviceへ集約する。

配置先は次を第一候補とする。

```text
src/book_manager/services/csv_export_service.py
```

クラス名は次とする。

```text
CsvExportService
```

### 9.1 CsvExportServiceの責務

`CsvExportService`は次を担当する。

1. 書籍一覧をCSV形式へ変換する。
2. CSVヘッダーを出力する。
3. `BookItem`をCSV行へ変換する。
4. `None`を空欄へ変換する。
5. 指定されたPathへCSVファイルを書き込む。
6. UTF-8 BOM付きで出力する。
7. CSV作成時の例外を呼び出し元へ伝える。

GUI表示やファイル保存ダイアログは`CsvExportService`の責務には含めない。

---

## 10. BookServiceとの関係

CSVエクスポートに必要な書籍一覧は、既存の`BookService`から取得することを基本方針とする。

Version 1.1では、CSV出力のためにRepositoryへ直接アクセスする構成は避ける。

概念上の流れは次のとおりとする。

```text
BookManagerApplication
        ↓
BookService
        ↓
登録済み書籍一覧
        ↓
CsvExportService
        ↓
CSVファイル
```

既存の責務分離を維持し、GUIがRepositoryへ直接依存しない構成とする。

---

## 11. GUIとの連携

CSVエクスポート機能は、`BookManagerApplication`から利用できるようにする。

Version 1.1では、操作ボタン領域に
「CSVエクスポート」ボタンを追加する。

「再読み込み」ボタンの右側、「終了」ボタンの左側へ配置する。

### 11.1 保存先選択

Tkinterのファイル保存ダイアログを使用し、利用者が保存先とファイル名を指定できるようにする。

第一候補は次とする。

```python
tkinter.filedialog.asksaveasfilename(...)
```

### 11.2 キャンセル

保存ダイアログでキャンセルした場合は、CSVファイルを作成しない。

キャンセルをエラーとして扱わず、エラーダイアログも表示しない。

### 11.3 成功時

CSVエクスポートが正常終了した場合は、完了メッセージを表示する。

例：

```text
CSVエクスポートが完了しました。
```

### 11.4 失敗時

CSVファイルの作成または保存に失敗した場合は、エラーメッセージを表示する。

例：

```text
CSVファイルを保存できませんでした。
```

詳細な例外情報は必要に応じて開発時の診断へ利用する。

---

## 12. 登録データが0件の場合

登録済み書籍が0件の場合は、CSVファイルを作成しない。

利用者へ次の内容を通知する。

保存ダイアログを出す前に0件を判定する

```text
エクスポートできる書籍がありません。
```

---

## 13. エラー処理

CSV出力で例外が発生した場合、`CsvExportService`は例外を握りつぶさず、呼び出し元へ伝える。

GUI側で例外を捕捉し、利用者へエラーを通知する。

次のような責務分離とする。

```text
CsvExportService
       ↓
CSV作成中に例外
       ↓
例外を呼び出し元へ送出
       ↓
BookManagerApplication
       ↓
例外を捕捉
       ↓
messageboxでエラー表示
```

---

## 14. テスト方針

`CsvExportService`には自動テストを追加する。

配置先は次を予定する。

```text
tests/services/test_csv_export_service.py
```

主なテスト項目は次のとおりとする。

### 14.1 基本出力

* CSVファイルを作成できる。
* ヘッダーが指定した12列で出力される。
* `BookItem`の値が正しい列順で出力される。
* 複数書籍を複数行で出力できる。

### 14.2 None

* `None`が空欄として出力される。

### 14.3 読書状態

* `unread`が「未読」として出力される。
* `reading`が「読書中」として出力される。
* `completed`が「読了」として出力される。
* `reading_status`が`None`の場合は空欄として出力される。
* 読了年月と読書状態を独立して出力できる。

### 14.4 特殊文字

* 内容紹介の改行が保持される。
* 備考の改行が保持される。
* カンマを含む文字列が正しく保持される。
* ダブルクォートを含む文字列が正しく保持される。

### 14.5 文字コード

* UTF-8 BOM付きで出力される。
* 日本語を読み戻した場合に文字化けしない。

### 14.6 日時

* 登録日時が出力される。
* 更新日時が出力される。
* デフォルトファイル名を生成する場合、指定した日時から安定して生成できる。

### 14.7 エラー処理

- 書き込み先で例外が発生した場合に例外が呼び出し元へ伝わる。
- Version 1.1では、書き込み途中に生成されたCSVファイルを
  CsvExportServiceが自動削除する処理は実装しない。

## 15. Version 1.1で実装しない範囲

次の機能はVersion 1.1のCSVエクスポートには含めない。

* CSVインポート
* 選択した書籍だけのCSV出力
* 検索結果だけのCSV出力
* 出力カラムの選択
* 出力カラム順の変更
* 文字コードの選択
* CSV区切り文字の変更
* 表紙画像そのものの出力
* CSVからのDB復元
* 定期的な自動CSV出力

これらは実利用結果を踏まえてVersion 1.2以降で検討する。
